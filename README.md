# Волейстат — iOS launcher

Ссылка на веб-приложение уже записана в index.html. Откройте опубликованный HTTPS-адрес в Safari и добавьте на экран «Домой». Для ручной смены адреса на одном устройстве откройте страницу лаунчера с ?setup=1.

Публикуйте содержимое архива в корне статического сайта. Целевое приложение должно разрешать iframe. Если полоса снизу находится внутри целевого приложения, исправлять нужно CSS самого приложения Apps Script.
